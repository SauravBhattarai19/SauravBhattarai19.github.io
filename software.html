Software

Open tools, free to run.

Two projects carry the dissertation: the GeoClimate Intelligence Platform opens Earth data to people who do not program, and MRRpy turns those data into floods. Both are free, documented, and already used in teaching. The code behind my published papers is public too.

Python package · lead developer

MRRpy

The Multi-Mechanism Runoff and Routing model: rainfall–runoff and flood routing for any basin on Earth, from a DEM and a storm. It traces the drainage network of a DEM, works out how much rain runs off, routes the water through every grid cell and sub-grid river channel, and reports the outlet hydrograph, flood maps, and a water-balance check.

Install

pip install MRRpy            # core (CPU)
pip install "MRRpy[gpu]"     # + CuPy/CUDA acceleration
pip install "MRRpy[gee]"     # + Google Earth Engine forcing

Run, given only an outlet

from MRRpy import Config, run_pipeline

cfg = Config(DEM_PATH="dem.tif", OUTPUT_DIR="results/",
             OUTPUT_POINT=(27.632, 85.293),   # (lat, lon) of the outlet
             TARGET_CRS_EPSG="EPSG:32645")    # a projection in metres
run_pipeline(cfg)                             # results/hydrograph.csv
MRRpy wizard            # answer a few questions, get run.yaml
MRRpy run -c run.yaml   # process the DEM and route the storm

What it offers

  • DEM to watershed. Reproject, pit-fill, D8 flow direction and accumulation, and delineation, or route the whole DEM with no outlet.
  • Runoff generation. Coefficient, raster, SCS curve number, or physical runoff: variable source area saturation excess, Green–Ampt infiltration with recovery, and impervious surfaces as composable mechanisms.
  • Flood routing. Kinematic wave, Muskingum–Cunge, a semi-implicit diffusion wave solved exactly on the drainage tree, and a local-inertial dynamic wave, with sub-grid river channels sized from the 2-year flood and an always-on water-balance check.
  • Satellite forcing. Optional DEM download, IMERG rainfall, curve numbers, SERVES soil deficit, SoilGrids, HiHydroSoil, and land cover from Google Earth Engine; every option also works offline with your own files.
  • Flood maps. Depth and discharge maps over time, animations, and peak-depth GeoTIFFs.
  • CPU or GPU. One code path in NumPy or CuPy, with automatic CPU fallback; 34 times faster on GPU at 1.38 million cells.
  • Interfaces for every taste. Python API, a command line with a question-and-answer wizard, a Jupyter form, and a QGIS plugin.

Web platform · lead developer

GeoClimate Intelligence Platform

A Streamlit web platform on Google Earth Engine that lets students, engineers, and researchers search, analyze, and export environmental data in a browser: 1,042 datasets and 23 climate indices, with no code. Free for research and teaching.

  1. Tool 1

    GeoData Explorer

    Search and download from the STAC API and Earth Engine catalog, with map preview, flexible areas, and GeoTIFF, NetCDF, or CSV export.

  2. Tool 2

    Climate Intelligence Hub

    ETCCDI climate indices such as TXx, RX1day, and CDD, with Mann–Kendall trend tests, time series, and maps.

  3. Tool 3

    Hydrology Analyzer

    Precipitation analysis with return periods, frequency analysis, IDF curves, and drought indices.

  4. Tool 4

    Optimal Product Selector

    Compares station data with gridded datasets to find the best source, from daily values to extremes.

  5. Tool 5

    Multi-Geometry Export

    Time series for many areas in one file, such as every county in a state.

  6. Tool 6

    Data Visualizer

    Upload results from any tool and explore time series and rasters with charts and summaries.

  7. Tool 7

    Raster Calculator

    Band math on any Earth Engine dataset: NDVI, NDWI, EVI, or custom expressions, with temporal aggregation.

  8. Tool 8

    GLOBAL-SAM

    Monthly snow depth from MODIS and GLDAS with an ERDC algorithm, compared against reference data.

  9. Tool 9

    SERVES

    Soil moisture, snow water equivalent, and land-surface analysis with the method of Dr. Nawa Raj Pradhan (ERDC).
